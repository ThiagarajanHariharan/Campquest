## 2024-05-24 - Accessibility improvements for interactive elements
**Learning:** The React app used non-accessible `div` elements for toggle switches, lacked `htmlFor` attributes connecting `label`s to their corresponding inputs in multiple forms (Login, Meal, Fitness), and was missing `aria-label`s on icon-only buttons. Using `div`s for toggles meant screen reader and keyboard users couldn't access or operate them.
**Action:** Replaced `div` toggles with `<button role="switch">` and set appropriate `aria-checked` and `aria-label` properties. Connected all `<label>`s to their respective `<input>` and `<select>` elements using matching `htmlFor` and `id` attributes. Added descriptive `aria-label`s to all icon-only buttons (close, logout, open menu, settings) and added global `:focus-visible` CSS rules to enhance keyboard navigation visibility.
